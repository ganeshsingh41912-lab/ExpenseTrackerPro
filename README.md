# 💰 ExpenseTrackerPro

A Python-based personal finance tracker to manage income, expenses, and spending categories.

## ✨ Features

- Add income and expenses
- Categorize expenses
- View transaction history
- Check current balance
- Generate category-wise reports
- Save and load data using JSON
- Monthly income and expense report (under development)

## 🛠️ Technologies Used

- Python
- JSON
- datetime module

## ▶️ How to Run

1. Install Python 3.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

   python main.py
